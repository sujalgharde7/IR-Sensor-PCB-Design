# IR Sensor PCB Design

## 📌 Project Overview

This project involves the design of a compact **IR Sensor PCB** developed using **KiCad**. The PCB was designed with proper component placement, copper routing, grounding, board outline, and manufacturing considerations.

The final design was exported as **Gerber and NC Drill files**, making it suitable for PCB fabrication.

## 🛠️ Tools Used

- KiCad
- PCB Layout Editor
- Gerber Viewer

## 🔧 Key Skills

- PCB Design
- PCB Layout
- Component Placement
- PCB Routing
- Grounding
- Layer Management
- Design Rule Checking (DRC)
- Gerber File Generation
- NC Drill File Generation
- PCB Manufacturing Preparation

## 📂 Project Files

The repository contains the manufacturing files required for PCB fabrication:

- **F_Cu** – Front Copper Layer
- **B_Cu** – Back Copper Layer
- **F_Mask** – Front Solder Mask
- **B_Mask** – Back Solder Mask
- **F_Silkscreen** – Front Silkscreen
- **B_Silkscreen** – Back Silkscreen
- **F_Paste** – Front Paste Layer
- **B_Paste** – Back Paste Layer
- **F_Courtyard / B_Courtyard** – Component Courtyard Layers
- **Edge_Cuts** – PCB Board Outline
- **PTH Drill** – Plated Through-Hole Drill File
- **Gerber Job File** – Manufacturing job information

## ⚙️ Design Process

1. Created the PCB design in KiCad.
2. Placed components according to the circuit requirements.
3. Defined the PCB board outline.
4. Routed the required copper traces.
5. Added appropriate grounding and clearances.
6. Checked the PCB layout for design constraints.
7. Generated Gerber files for manufacturing.
8. Generated NC Drill files for drilling operations.
9. Reviewed the generated manufacturing files.

## 📦 Manufacturing Output

The final **Gerber package** includes the copper, solder mask, silkscreen, paste, board outline, courtyard, and drill files required for PCB fabrication.

## 🎯 Project Outcome

Successfully developed a fabrication-ready **IR Sensor PCB layout** and generated the required manufacturing files. This project provided practical experience in the complete PCB design workflow using KiCad, from PCB layout and routing to Gerber generation.
